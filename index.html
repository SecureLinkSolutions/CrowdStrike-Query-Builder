IOC query builder

Paste indicators from an advisory, spreadsheet or report. They are refanged, sorted by type and turned into searches and lookup files. Everything is processed in this page: nothing you paste is uploaded, and the page blocks all network requests.

      Options
      What this supports

      Selections as maps, lists of maps and keyword lists. Conditions with and, or, not, brackets, 1 of, all of and them. Modifiers contains, startswith, endswith, all, re, cidr, exists, cased, fieldref, gt, gte, lt, lte, base64, base64offset, wide, utf16le, utf16be, utf16 and windash.

      Pipelines support field_name_mapping, field_name_prefix, drop_detection_item (with fields), add_condition and set_state, with logsource rule conditions. The presets are starting points, so check the field names against your own data.

      Not supported: count() and near aggregations, correlation rules, action: global and expand placeholders. This is a JavaScript reimplementation, not pySigma itself, so test generated queries before deploying them.

      Converted queries

      Runs entirely in your browser. The page's content security policy blocks every outbound connection, and downloads are generated locally. Browser extensions are not bound by that policy and can read what you paste, so use a browser profile with no extensions for restricted material. Grammarly is told to ignore every field.

      Builds CrowdStrike Falcon NG-SIEM (LogScale) and Splunk (SPL) searches. Supports IPv4, CIDR, SHA256, SHA1, MD5, domains, URLs, paths and file names. Octets above 255 and invalid CIDR prefixes are rejected.

      The Sigma tab converts Sigma rules to Falcon NG-SIEM, Splunk, Elastic Lucene and Microsoft KQL with a parser built into this page. It makes no network requests either.
