IOC query builder for Falcon NG-SIEM

Paste indicators from an advisory, spreadsheet or report. They are refanged, sorted by type and turned into LogScale searches and lookup files. Everything is processed in this page: nothing you paste is uploaded, and the page blocks all network requests.

Indicators

Paste indicators in any format: one per line, spreadsheet rows or free text. If rows include a type column, it is used. Common defanging is undone automatically.

Advisory details

Detected from the pasted text when a TLP marking is present.

Options

Allowlist

Indicators listed here are removed before queries are built. Domains also cover their subdomains, and ranges cover every address inside them.

Saved sessions

Off by default. Sessions are stored in this browser only and never sent anywhere. Turning this off deletes them.
