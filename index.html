IOC query builder

Paste indicators from an advisory, spreadsheet or report. They are refanged, sorted by type and turned into searches and lookup files. Everything is processed in this page: nothing you paste is uploaded, and the page blocks all network requests.

      Runs entirely in your browser. The page's content security policy blocks every outbound connection, and downloads are generated locally. Browser extensions are not bound by that policy and can read what you paste, so use a browser profile with no extensions for restricted material. Grammarly is told to ignore every field.

      Builds CrowdStrike Falcon NG-SIEM (LogScale) and Splunk (SPL) searches. Supports IPv4, CIDR, SHA256, SHA1, MD5, domains, URLs, paths and file names. Octets above 255 and invalid CIDR prefixes are rejected.
